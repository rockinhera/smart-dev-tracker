
# Smart Dev Habit & Task Tracker

A simple React app for tracking developer habits, tasks, focus time, and productivity.

## Live Preview

[View Live Website](https://rockinhera.github.io/smart-dev-tracker/)

## Features:

* Track daily habits.
* Manage tasks.
* Track focus time.
* Maintain streaks.
* View productivity statistics.
* Responsive design.

## Built With:

* React.js
* Tailwind CSS
* Vite
* JavaScript
